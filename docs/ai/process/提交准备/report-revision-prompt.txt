# 《守灯人》

《守灯人》（THE LANTERN KEEPER）是一款以传统丧葬文化当代传承为主题的网页 3D 叙事游戏，参加群核科技 Aholo 全球 3D AI 黑客松。玩家扮演白事店年轻店主阿舟，在斜俯视的剖面场景中走动、查看物件、与人物交谈，并用双手完成一件件具体的活计。作品用纯 HTML/CSS/JavaScript 与 Three.js r180 写成，运行于浏览器。

## 一、主题：把丧葬文化写成一件件手上的事

白事店的灯、花圈、账簿、木刨、相框，都是乡村生活里真实存在的物件。作品把这些物件放回具体的人与家庭之中：谁家的老人走了，谁家的旧照缺了一角，谁想把父亲的刨子好好收起来。玩家不需要背诵任何礼俗条规，而是在挪凳、留路、移灯、合门、拼照、装框、比对刨口的过程中，慢慢明白这些动作在丧礼上的分量。

丧葬文化的传承在这部作品里表现为一套仍在被人使用的做法：一个人接着一个人的手，把活干完，把话说尽。灯在门口亮着，来吊唁的人有路可走，旧照能立起来，工具能找到它的位置。

## 二、剧情结构

故事从病房开始。阿舟在病床前听奶奶说完最后的嘱托，回到白事店备物，主持并为奶奶送别。秋天，他替林、王、杜三家处理托办的事。入冬后，小店的进货和县城来信同时摆在面前，他要在进城与留村之间做一次选择。

- **开篇**：病房诀别、白事店备物、送别奶奶。
- **秋日三家**：林家、王家、杜家各一场托办，经营阶段为可选。
- **冬日的选择**：面对进货与来信，做出进城或留村的选择。
- **两条路线**：进城线与留村线各有两幕与一段尾声，尾声页面提供“从头开始”。

主线通过场景推进：玩家与人物对话、查看线索物件、完成动手操作后，故事继续向下走。笔记本分为人物、故事、物件三栏，收集到的内容随剧情解锁新段落；已收集的物件可以旋转和缩放查看。笔记本与分支进度、谜题完成姿态保存在同一浏览器中，刷新后可以接着玩。

## 三、核心体验与操作

场景采用斜俯视视角，房间和院落以剖面形式呈现。玩家用 WASD 或方向键沿画面方向走动，触屏设备使用画面左下方的方向按钮；按 Shift 或点底部按钮切换步行与奔跑；靠近菱形标记后按 E 交互、继续对话；按 N 打开笔记本；查看物件时按 Esc 关闭。

三处谜题都要求玩家在 3D 空间里真正动手：

- **林家**：把凳子挪开，留出通行的路；端水试走；移动灯的位置，合上大门，再到门外看一眼。
- **王家**：把六块旧照拼合完整，装进相框，拨动相框背撑，试立在桌面上；随后把相框安放到木槽中，再到门边观察。
- **杜家**：翻看刨底，对照刨痕，在几种托座里选出合适的那一只，再把刨子安放进去。

谜题操作以拖动为主，配合转向按钮与方向键微调，按屏幕上的具体提示进行。经营单、当前谜题、本场葬礼和整个经营阶段都设有跳过入口，玩家可以按自己的节奏推进。经营阶段本身是可选内容，跳过它也可以读完两条路线。

## 四、Lux3D 在项目中的位置

Aholo Lux3D 承担了作品里几乎全部可见的三维形体。核心角色、重要布景和互动道具都以 GLB 形式接入场景：卧姿奶奶与病床、竹凳、柜台、木柜、祠堂门廊与长案、花圈支架、桂花与开花花枝、窄凳、工作台、卷帘门、玻璃罐、相框、木刨、带刨痕木料、木托、纸箱、牛皮纸信封、行李、木门、素白纸花、纸料、门牌等。这些模型与笔记本中的物件预览共用同一份文件，玩家在场景里看到的物件，翻开笔记拿在手里转的也是同一件。

主角阿舟通过 Lux3D 的文生 3D 与自动绑骨得到，步行与奔跑动画取自卡内基梅隆大学图形实验室的动作捕捉数据 07_06、09_06，并已转到主角骨架上。

## 五、资产创作流程

本项目采用的流程是：先用内置 ImageGen 生成参考图，再经 Aholo Lux3D 图生 3D 导出 GLB，最后按游戏尺寸与纹理需要处理并接入场景。

参考图承担统一风格的作用。每张提示词都写明物件是什么、什么角度、什么光、什么背景：比如柜台要写成“1920 毫米宽、深蜜色台面、抽屉只在背面、台面上不放东西”，相框要写成“深胡桃木边框、内部空着、背后有撑脚”，木刨要写成“25 厘米长的蜜色硬木、能看到刨口”。统一的白色背景和三视角构图让图生 3D 有稳定的输入。生成参数按用途区分：病床奶奶使用 G1，目标 80,000 面；其余多数新增道具和 NPC 使用 G1-Turbo，目标 10,000 面。面数是生成时设定的目标，最终文件的面数以来源表实际记录为准。

## 七、最终画面

三处经营场景共享墙地结构，各自配上门廊、卷帘柜台或木工台，从秋天的院落走到冬天的店铺，再走到第二年春天的柜台。场景灯光克制，纸料、木器、白布与花枝构成主要色块，人物站位与物件摆放都留出通行的余地，让玩家一眼看到该去哪儿。

病房的低饱和绿、祠堂的旧红木、王家柜台的暖蜜色、杜家木工台上的刨花，这些颜色来自参考图，也来自 Lux3D 生成的模型纹理，在网页里保持了连贯的观感。

## 八、技术与运行

项目采用纯 HTML/CSS/JavaScript 实现，使用 Three.js r180，以 GLTFLoader 加载 GLB；vendor 依赖随仓库提供，无需 npm 构建，没有后端服务，游玩过程中不调用生成 API。现代浏览器需要支持 WebGL 2。离线游玩需通过本地 HTTP 服务打开，在仓库根目录执行：

```
python -m http.server 8765 --bind 127.0.0.1 --directory game
```

然后访问 http://127.0.0.1:8765/。

源码仓库为 https://github.com/lycshanshan/aholo-hackathon ，游戏文本以 JSON 存放在 `game/data/`，场景位置与动作触发条件配置在 `game/src/chapters.js`。
